# Workfront Fusion 릴리스 활동: 2026년 10월 5일이 있는 주

이 페이지에서는 2026년 10월 5일이 있는 주에 Adobe Workfront Fusion에서 향상된 모든 기능에 대해 설명합니다.

최근 모든 변경 사항의 목록은 [Adobe Workfront Fusion 릴리스 활동](/help/workfront-fusion/fusion-product-releases/fusion-release-activity.md)을 참조하십시오.

Workfront Fusion의 최근 버그 수정 목록을 보려면 [Workfront 유지 관리 업데이트](https://experienceleague.adobe.com/ko/docs/workfront-known-issues/releases/current-updates) 페이지를 참조하고 Workfront Fusion 유지 관리 업데이트 레이블이 지정된 업데이트를 확인하십시오.

## Jira 커넥터: 새 서비스 계정 연결 유형

팀의 인증 방식과 일치하는 Jira 연결을 더 쉽게 만들 수 있도록 Jira 커넥터에 서비스 계정 API 토큰 및 서비스 계정 OAuth 2라는 두 가지 새로운 연결 유형을 추가했습니다.

이러한 옵션을 사용하면 개인 사용자 계정 대신 전용 Jira 서비스 계정으로 실행해야 하는 자동화를 위한 연결을 만들 수 있습니다. Jira 서비스 계정이 API 토큰으로 인증될 때 서비스 계정 API 토큰을 사용하고, 환경에서 서비스 계정에 OAuth 2를 사용할 때 서비스 계정 OAuth 2를 사용합니다.

기본 및 OAuth2 연결 유형은 계속 사용할 수 있습니다.

자세한 내용은 [Jira 모듈](/help/workfront-fusion/references/apps-and-modules/third-party-connectors/jira-modules-new.md)을 참조하세요.

## Veeva Vault 커넥터에 사용할 수 있는 새로운 다중 주석 생성 모듈

여러 주석 만들기 모듈을 더 쉽게 사용할 수 있도록 새 모듈로 업데이트했습니다. 이제 값을 제공하기 전에 배치 표시, 참조 및 기타 주석 필드에 대한 필드를 선택할 수 있으므로 구성을 단순화하고 우선 순위가 지정된 값에만 집중할 수 있습니다.

이전에 사용 가능했던 여러 주석 만들기 모듈은 계속 사용할 수 있으며 &quot;레거시&quot;으로 표시됩니다.

Veeva Vault 모듈에 대한 자세한 내용은 [Veeva Vault 모듈](/help/workfront-fusion/references/apps-and-modules/third-party-connectors/veeva-vault-modules.md)을 참조하십시오.



## HTTP > 요청 모듈에 추가 재시도 상태 코드 추가

HTTP 요청 재시도를 보다 세밀하게 제어할 수 있도록 HTTP > 요청 만들기 모듈에 및 추가 재시도 상태 코드 필드를 추가했습니다.

이제 내장된 재시도 가능 코드(408, 429 및 모든 5xx 응답) 외에도 재시도 가능한 것으로 처리되어야 하는 사용자 지정 HTTP 상태 코드를 정의할 수 있습니다. 예를 들어 이제 422 응답을 재시도할 수 있습니다. T

자세한 내용은 [HTTP > 요청 모듈 만들기](/help/workfront-fusion/references/apps-and-modules/universal-connectors/http-module-make-a-request.md)를 참조하십시오.

## HTTP > JWT 요청 만들기 모듈을 사용하여 서명된 JWT 인증을 HTTP 요청에 추가합니다.

서명된 JWT 인증이 필요한 API를 더 쉽게 호출할 수 있도록 HTTP > JWT 요청 만들기 모듈을 추가했습니다.

이 모듈은 표준 HTTP > 요청 모듈 만들기와 같이 작동하지만 사용자가 제공하는 클레임에서 JSON 웹 토큰을 자동으로 생성하고 서명하여 요청에 기본적으로 인증 전달자 토큰으로 포함합니다. 이렇게 하면 시나리오에서 별도의 토큰 생성 단계를 만들지 않고도 단기 JWT 기반 액세스가 필요한 서비스를 인증할 수 있습니다.

자세한 내용은 [HTTP > JWT 요청 모듈 만들기](/help/workfront-fusion/references/apps-and-modules/universal-connectors/http-module-make-a-jwt-request.md)를 참조하십시오.
