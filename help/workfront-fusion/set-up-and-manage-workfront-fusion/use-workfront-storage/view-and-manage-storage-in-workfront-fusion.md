# Workfront Fusion의 스토리지 보기 및 관리

Workfront Fusion의 저장소 영역에서 Adobe 클라우드 저장소의 저장소를 보고 상호 작용할 수 있습니다.

저장소 개요는 [저장소 개요](/help/workfront-fusion/set-up-and-manage-workfront-fusion/use-workfront-storage/storage-overview.md)를 참조하십시오.

>[!TIP]
>
>저장소를 보려면 먼저 저장소를 초기화해야 합니다. 자세한 내용은 [저장소 초기화](/help/workfront-fusion/set-up-and-manage-workfront-fusion/use-workfront-storage/initialize-storage.md)를 참조하십시오.

## 저장소, 폴더 및 파일 보기

1. Workfront Fusion의 왼쪽 탐색에서 **저장소**를 클릭합니다.
저장소 목록이 열립니다.

   사용 가능한 저장소가 한 개만 있는 경우 저장소가 바로 열립니다.

1. 저장소에서 **열기**&#x200B;를 클릭하여 내용을 찾아봅니다.

   저장소를 열면 저장소 내의 폴더가 표시됩니다.
1. 폴더를 클릭하여 열고 해당 파일을 표시합니다.
1. 폴더 구조를 다시 탐색하려면 탐색 표시를 클릭합니다.


>[!NOTE]
>
>빈 폴더에 메시지가 표시됩니다. *&quot;이 폴더는 비어 있습니다.&quot;*

## 여러 스토리지 접속 관리

한 팀에는 여러 Adobe 스토리지 연결이 있을 수 있습니다.

1. Workfront Fusion의 왼쪽 탐색에서 **저장소**를 클릭합니다.
접속이 여러 개 있는 경우 스토리지 페이지 상단에 각 접속의 이름으로 레이블이 지정된 탭이 나타납니다.
1. 다른 연결의 저장소로 전환하려면 해당 연결에 대한 탭을 클릭합니다.

토큰이 만료되어 새로 고칠 수 없는 경우와 같이 연결이 유효하지 않게 되면 자동으로 필터링되고 탭으로 표시되지 않습니다. Fusion의 예약된 토큰 새로 고침은 연결을 자동으로 유효하게 유지합니다.

## 파일 정보

표의 각 파일은 다음과 같습니다.

| 열 | 설명 |
| -------- | ------------- |
| **이름** | 문서 아이콘이 있는 파일 이름. |
| **유형** | PNG, PDF 또는 JPG과 같은 파일 확장명 배지. |
| **크기** | 파일 크기. 파일이 최근에 업로드되고 백엔드가 아직 처리 중인 경우 *&quot;처리 중...&quot;*&#x200B;을(를) 표시합니다. |
| **생성일** | 제작일. |

여러 버전이 있는 경우 파일에 **버전 배지**(예: `v2`, `v3`)가 표시됩니다.

## 테이블 컨트롤

* **검색/필터**: 전역 검색 창을 사용하여 이름별로 파일을 필터링합니다.
* **정렬**: 정렬할 열 머리글을 클릭합니다.
* **페이지 매김**: 페이지당 10개, 25개, 50개 또는 100개의 항목을 선택합니다. 기본값은 25입니다.
