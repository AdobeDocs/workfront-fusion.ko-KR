# Workfront Fusion 릴리스 활동: 2026년 10월 19일이 있는 주

이 페이지에서는 2026년 10월 19일이 있는 주에 Adobe Workfront Fusion에서 향상된 기능을 모두 설명합니다.

최근 모든 변경 사항의 목록은 [Adobe Workfront Fusion 릴리스 활동](/help/workfront-fusion/fusion-product-releases/fusion-release-activity.md)을 참조하십시오.

Workfront Fusion의 최근 버그 수정 목록을 보려면 [Workfront 유지 관리 업데이트](https://experienceleague.adobe.com/ko/docs/workfront-known-issues/releases/current-updates) 페이지를 참조하고 Workfront Fusion 유지 관리 업데이트 레이블이 지정된 업데이트를 확인하십시오.

## 편집 가능한 작업자 풀 이름

조직 소유자 및 관리자는 이제 조직에 할당된 작업자 풀의 이름을 변경할 수 있습니다. 지금까지 각 풀에는 시스템에서 생성한 고정된 이름이 표시되었습니다. 이제 풀에 사용자 정의 이름을 지정하고 필요할 때마다 변경할 수 있습니다.

자세한 내용은 [작업자 풀](/help/workfront-fusion/set-up-and-manage-workfront-fusion/licensing-operations-overview/worker-pools.md)을 참조하세요.

## 새 매핑 변수

이제 매핑 패널에서 6개의 새 일반 변수를 사용할 수 있습니다. 바로 사용 가능한 시나리오 및 실행 링크, API URL 및 소유권 식별자를 제공하므로 URL을 작성하거나 팀 및 조직 ID를 하드코딩하지 않고 매핑된 필드에 이러한 값을 포함할 수 있습니다.

* `scenarioUrl`: Fusion 사용자 인터페이스의 현재 시나리오에 대한 링크입니다.
* `executionUrl`: Fusion 사용자 인터페이스의 현재 시나리오 실행에 대한 링크입니다.
* `scenarioApiUrl`: 현재 시나리오의 Fusion API URL입니다.
* `executionApiUrl`: 현재 실행에 대한 세부 정보의 Fusion API URL입니다.
* `teamId`: 현재 시나리오를 담당하는 Fusion 팀의 ID입니다.
* `organizationId`: 현재 실행과 연결된 Fusion 조직의 ID입니다.

이 변수는 기존 `executionID`, `scenarioID`, `scenarioName`, `triggerTimestamp` 및 `operationsConsumed` 변수를 확장합니다.

자세한 내용은 [일반 함수](/help/workfront-fusion/references/mapping-panel/functions/general-functions.md)를 참조하십시오.

## Fusion 커넥터 변경 사항

이제 Workfront Fusion 커넥터는 시나리오 내에서 Fusion 조직을 관리하기 위한 추가 작업을 지원합니다.

**새 모듈 및 작업**

* **레코드 복제:** 이제 후크를 복제할 수 있습니다. 시나리오를 복제할 때와 마찬가지로 종속성을 사용하여 소스 후크의 종속성을 대상에 매핑합니다.
* **레코드 삭제:** 이제 연결, 데이터 저장소, 데이터 저장소 레코드, 데이터 저장소 레코드(대량), 데이터 구조, 후크, 키, 시나리오 또는 팀을 삭제할 수 있습니다.
* **레코드 나열:** 이제 DLQ, 조직, 팀 및 사용자를 나열할 수 있습니다.
* **레코드 읽기:** 이제 DLQ, 현재 조직, 팀, 사용자 또는 인증된 사용자를 읽을 수 있습니다.
* **레코드 종속성 가져오기:** 이제 후크의 종속성을 가져올 수 있습니다.
* **레코드 종속 항목 가져오기:** 이 새 모듈은 데이터 저장소, 후크 및 시나리오의 종속 항목을 반환합니다. 리소스를 삭제하기 전에 실행하여 종속된 항목이 있는지 확인합니다.

**기타 업데이트**

* 다중 값으로 표시된 속성 필터는 이제 `==` 및 `!=` 연산자로 쉼표로 구분된 값을 허용합니다. 현재 사용자의 `id` 속성만 지원합니다(예: `id==123,456`).
* 후크의 큐를 삭제할 때 `except` 매개 변수는 `excludeId`을(를) 대체하며 모든 항목을 삭제할 때만 사용할 수 있습니다. 이제 `id` 매개 변수가 쉼표로 구분된 목록을 허용합니다. 삭제가 이미 진행 중이면 새 423 응답이 반환됩니다.
* 이제 시나리오 또는 단일 시나리오를 가져올 때 `fields` 매개 변수를 사용하여 반환되는 필드를 선택할 수 있습니다.

자세한 내용은 [Workfront Fusion 모듈](/help/workfront-fusion/references/apps-and-modules/adobe-connectors/workfront-fusion-modules.md)을 참조하십시오.

## Adobe Fusion MCP 커넥터

새로운 Adobe Fusion MCP 커넥터를 사용하면 시나리오 내에서 자연어 프롬프트를 Adobe Fusion MCP 서버로 보낼 수 있습니다. LLM(Large Language Model)은 요청을 해석하고 완료하는 데 필요한 Fusion 도구를 호출합니다.

커넥터는 호스팅되는 Adobe Fusion MCP 끝점에서만 작동합니다.

자세한 내용은 [Adobe Fusion MCP 모듈](/help/workfront-fusion/references/apps-and-modules/adobe-connectors/adobe-fusion-mcp-modules.md)을 참조하십시오.
