# Workfront Fusion 릴리스 활동: 2026년 8월 17일 주

이 페이지에서는 2026년 8월 17일이 있는 주에 Adobe Workfront Fusion에서 향상된 모든 기능에 대해 설명합니다.

최근 모든 변경 사항의 목록은 [Adobe Workfront Fusion 릴리스 활동](/help/workfront-fusion/fusion-product-releases/fusion-release-activity.md)을 참조하십시오.

Workfront Fusion의 최근 버그 수정 목록을 보려면 [Workfront 유지 관리 업데이트](https://experienceleague.adobe.com/ko/docs/workfront-known-issues/releases/current-updates) 페이지를 참조하고 Workfront Fusion 유지 관리 업데이트 레이블이 지정된 업데이트를 확인하십시오.

## Workfront Fusion에서 사용자 정의 UI 확장 빌드

이제 Workfront App Builder 및 Adobe UI Extensibility SDK을 사용하여 사용자 지정 UI로 Adobe Fusion 인터페이스를 확장할 수 있습니다.

사용자 지정 UI 확장은 빌드하고 Adobe에 게시하는 작은 웹 앱입니다. 게시되면 Fusion 탐색의 버튼으로 표시됩니다. 사용자가 클릭하면 사용자 정의 화면이 Fusion 내부에 직접 로드되고 로그인한 사용자, 조직 및 팀에 대한 컨텍스트가 자동으로 수신됩니다.

사용자 정의 UI 확장을 사용하여 다음과 같은 작업을 수행할 수 있습니다.

* Fusion 자체를 수정하지 않고 Fusion 인터페이스 내부에 도구, 대시보드 또는 화면을 직접 추가합니다.
* 로그인한 사용자, 조직 및 팀과 같은 Fusion의 라이브 컨텍스트를 읽고 사용자가 조직 또는 팀을 전환할 때 자동으로 반응합니다.
* 보안된 동일 출처 프록시를 통해 확장에서 Workfront 및 Fusion API를 호출하여 브라우저 CORS 제한을 피하십시오.
* 전체 조직을 위해 게시하기 전에 스테이지 빌드로 확장을 비공개로 테스트합니다.

사용자 정의 UI 확장을 사용하려면 Adobe ID이 Adobe 조직에 액세스할 수 있고 개발자가 Adobe App Builder에 액세스할 수 있어야 합니다.

자세한 내용은 [사용자 지정 UI 확장: 문서 인덱스](/help/workfront-fusion/set-up-and-manage-workfront-fusion/configure-custom-extensions/custom-extension-00-readme.md)를 참조하십시오.

## Workfront Planning 레코드 모듈에서 매핑할 필드 선택

이제 Workfront Planning에서 레코드를 사용할 때 더 작고 효율적인 페이로드를 만들기 위해, Workfront Planning V2 커넥터의 **레코드 만들기**, **레코드 검색** 및 **레코드 업데이트** 모듈을 사용하면 사용 가능한 모든 필드를 전송하는 대신 값을 제공하거나 검색할 필드를 선택할 수 있습니다.

이러한 각 모듈에는 이 필드 선택 옵션을 포함하지 않는 해당 이전 버전이 있습니다. 모듈의 페이로드 크기를 줄이려면 새 버전으로 전환하는 것이 좋습니다.

자세한 내용은 [Adobe Workfront 계획 모듈](/help/workfront-fusion/references/apps-and-modules/adobe-connectors/workfront-planning-modules.md)을 참조하세요.

## 새로운 Adobe Workfront MCP 커넥터

이제 새로운 Adobe Workfront MCP 커넥터를 사용하여 Workfront Fusion을 Adobe Workfront의 자체 MCP(Model Context Protocol) 서버에 직접 연결할 수 있습니다.

각 모듈이 하나의 고정 작업을 수행하는 일반적인 커넥터와 달리 이 커넥터에는 하나의 &quot;사용자 프롬프트 처리&quot; 모듈이 있습니다. 개방형 일반 영어 지침을 제공하면 AI 모델이 이를 이행하는 데 필요한 Workfront 작업을 결정합니다. 예를 들어, 여러 Get 및 Filter 모듈을 함께 연결하는 대신 &quot;예정보다 늦은 활성 프로젝트를 모두 찾고 상태를 요약하십시오&quot;라는 메시지를 입력할 수 있습니다.

자세한 내용은 [Adobe Workfront MCP 모듈](/help/workfront-fusion/references/apps-and-modules/adobe-connectors/workfront-mcp-modules.md)을 참조하세요.

## 서비스 주체를 사용하여 Azure DevOps 및 SharePoint에 연결

이제 개인 계정 대신 서비스 주체(애플리케이션 API 연결)를 사용하는 Azure DevOps 또는 Microsoft SharePoint Online에 대한 연결을 만들 수 있습니다. 이 기능은 연결을 특정 사용자가 아닌 애플리케이션이나 서비스 ID로 실행하려는 경우 유용하며, 따라서 해당 사용자가 회사를 떠나거나 암호를 변경해도 통합이 중단되지 않습니다.

Azure DevOps의 경우, 이 연결 유형은 모든 Azure DevOps 모듈에 사용할 수 있습니다. SharePoint의 경우 API 호출 만들기 모듈에만 사용할 수 있습니다.

자세한 내용은 다음 문서를 참조하십시오.

* [Azure DevOps 모듈](/help/workfront-fusion/references/apps-and-modules/third-party-connectors/azure-dev-ops.md)
* [Microsoft SharePoint Online 모듈](/help/workfront-fusion/references/apps-and-modules/third-party-connectors/sharepoint-modules.md).
