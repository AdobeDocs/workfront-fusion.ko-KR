# Workfront Fusion 릴리스 활동: 2026년 8월 17일 주

이 페이지에서는 2026년 8월 17일이 있는 주에 Adobe Workfront Fusion에서 향상된 모든 기능에 대해 설명합니다.

최근 모든 변경 사항의 목록은 [Adobe Workfront Fusion 릴리스 활동](/help/workfront-fusion/fusion-product-releases/fusion-release-activity.md)을 참조하십시오.

Workfront Fusion의 최근 버그 수정 목록을 보려면 [Workfront 유지 관리 업데이트](https://experienceleague.adobe.com/ko/docs/workfront-known-issues/releases/current-updates) 페이지를 참조하고 Workfront Fusion 유지 관리 업데이트 레이블이 지정된 업데이트를 확인하십시오.

## Workfront Fusion에서 사용자 정의 UI 확장 빌드

이제 Workfront App Builder 및 Adobe UI Extensibility SDK을 사용하여 사용자 지정 UI로 Adobe Fusion 인터페이스를 확장할 수 있습니다.

사용자 지정 UI 확장은 빌드하고 Adobe에 게시하는 작은 웹 앱입니다. 게시되면 Fusion 탐색의 버튼으로 표시됩니다. 사용자가 클릭하면 사용자 정의 화면이 Fusion 내부에 직접 로드되고 로그인한 사용자, 조직 및 팀에 대한 컨텍스트가 자동으로 수신됩니다.

사용자 정의 UI 확장을 사용하여 다음과 같은 작업을 수행할 수 있습니다.

* Fusion 자체를 수정하지 않고 Fusion 인터페이스 내부에 도구, 대시보드 또는 화면을 직접 추가합니다.
* 로그인한 사용자, 조직 및 팀과 같은 Fusion의 라이브 컨텍스트를 읽고 사용자가 조직 또는 팀을 전환할 때 자동으로 반응합니다.
* 보안된 동일 출처 프록시를 통해 확장에서 Workfront 및 Fusion API를 호출하여 브라우저 CORS 제한을 피하십시오.
* 전체 조직을 위해 게시하기 전에 스테이지 빌드로 확장을 비공개로 테스트합니다.

사용자 정의 UI 확장을 사용하려면 Adobe ID이 Adobe 조직에 액세스할 수 있고 개발자가 Adobe App Builder에 액세스할 수 있어야 합니다.

자세한 내용은 [사용자 지정 UI 확장: 문서 인덱스](/help/workfront-fusion/set-up-and-manage-workfront-fusion/configure-custom-extensions/custom-extension-00-readme.md)를 참조하십시오.
