# Adobe Workfront Fusion MCP 서버 도구


이 문서에서는 Adobe Workfront Fusion MCP 서버가 연결된 AI 에이전트에 노출하는 도구를 나열합니다. Fusion 항목을 검색, 검사, 생성, 실행, 업데이트 또는 삭제하도록 요청하면 에이전트가 사용자를 대신하여 이러한 도구를 호출합니다.

Claude, ChatGPT, Copilot 또는 자체 에이전트의 사용자 정의 MCP 연결 및 독립 실행형 및 Fusion 오른쪽 레일의 Coworker와 같은 도구를 모든 지원되는 표면에서 사용할 수 있습니다. 설정에 대해서는 [Adobe Workfront Fusion MCP 서버 구성](configure-fusion-mcp-server.md)을 참조하십시오.

에이전트는 Adobe ID, Fusion 조직 역할 및 팀 역할을 사용하여 Fusion에서 작동합니다. 도구는 Fusion에서 해당 권한이 있는 경우에만 작동합니다. Adobe은 에이전트가 Fusion 데이터에 적용한 변경에 대해 책임을 지지 않습니다.

## 읽기 및 쓰기 작업

각 도구는 다음과 같이 분류됩니다.

* **읽기**: 시나리오 나열 또는 실행 가져오기와 같이 아무 것도 변경하지 않고 정보를 검색합니다.
* **쓰기**: 시나리오를 복제하거나 웹후크 큐를 지우는 것과 같은 Fusion 데이터를 만들거나, 변경하거나, 실행하거나, 삭제합니다.

## 조직 도구

활성 조직은 현재 세션의 다른 모든 도구에 적용됩니다.

| 도구 | 이름 | 작업 | 설명 |
| --- | --- | --- | --- |
| 조직 나열 | `fusion_orgs_list` | 읽기 | ID, 지역(영역) 및 레이블을 사용하여 액세스할 수 있는 Fusion 조직을 나열합니다. |
| 활성 조직 설정 | `fusion_orgs_set` | Session | 현재 세션에 대한 활성 조직을 전환합니다. Fusion 데이터는 변경되지 않습니다. |

## 시나리오 도구

### 시나리오

| 도구 | 이름 | 작업 | 설명 |
| --- | --- | --- | --- |
| 시나리오 나열 | `fusion_scenarios_list` | 읽기 | 조직의 시나리오를 나열합니다. |
| 시나리오 가져오기 | `fusion_scenarios_get` | 읽기 | 전체 블루프린트가 포함된 시나리오를 반환합니다. |
| 시나리오 종속성 가져오기 | `fusion_scenarios_getDependencies` | 읽기 | 시나리오의 블루프린트 참조에 대한 연결, 키, 데이터 저장소, 데이터 구조 및 웹후크를 반환합니다. |
| 종속 시나리오 찾기 | `fusion_scenarios_dependents` | 읽기 | 주어진 웹후크, 데이터 저장소, 데이터 구조, 연결, 키 또는 시나리오를 참조하는 시나리오를 찾습니다. 리소스를 변경하거나 삭제하기 전에 영향 분석에 유용합니다. |
| 블루프린트 유효성 검사 | `fusion_scenarios_validate_blueprint` | 읽기 | 아무것도 저장하지 않고 팀(모듈 참조, 연결, 필수 필드)에 대해 블루프린트의 구조를 확인합니다. |
| 시나리오 만들기 | `fusion_scenarios_create` | 쓰기 | 블루프린트에서 이름, 설명, 폴더, 예약 및 순차적 처리 옵션을 사용하여 팀에 시나리오를 만듭니다. |
| 복제 시나리오 | `fusion_scenarios_clone` | 쓰기 | 시나리오를 동일한 팀 또는 다른 팀으로 복제합니다. 팀 간에 복제할 때는 각 연결, 웹후크, 데이터 저장소, 데이터 구조 및 키를 대상 리소스에 매핑합니다. 선택적으로 마지막 처리된 레코드에서 계속합니다. |
| 시나리오 업데이트 | `fusion_scenarios_update` | 쓰기 | 이름, 설명, 폴더, 예약 또는 활성 상태(활성화/비활성화)를 변경합니다. 또한 삭제된 시나리오를 복원할 수 있습니다. |
| 시나리오 한 번 실행 | `fusion_scenarios_execute` | 쓰기 | 시나리오를 한 번 실행하고 결과를 기다린 후(최대 시간 초과) 상태 및 오류 메시지를 반환합니다. 즉각적인(웹후크에서 트리거되는) 시나리오에서는 지원되지 않습니다. |
| 시나리오 삭제 | `fusion_scenarios_delete` | 쓰기 | 시나리오를 삭제합니다. 삭제된 시나리오는 **시나리오 업데이트**(으)로 복원할 수 있습니다. |

프롬프트 예:

* _마케팅 팀에서 6개월 동안 편집하지 않은 활성 시나리오는 무엇입니까?_
* _Salesforce → Workfront 동기화 시나리오에서는 어떤 연결을 사용합니까?_
* _영업팀에 &quot;잠재 고객 접수&quot;를 복제하고 영업 Salesforce 연결에서 바꿉니다._
* _가져오기 전에 이 블루프린트의 유효성을 검사하십시오._
* _&quot;야간 보고서&quot;를 한 번 실행하고 성공 여부를 알려 주십시오._

## 연결 및 주요 도구

이 도구는 메타데이터만 반환합니다. 자격 증명, 토큰 또는 비밀 값을 반환하지 않습니다.

| 도구 | 이름 | 작업 | 설명 |
| --- | --- | --- | --- |
| 연결 검색 | `fusion_connections_search` | 읽기 | 연결을 나열합니다. `name`, `accountName`, `accountType`, `expire`, `teamId`, `scopesCount`, `editable`, `environmentType`, `authenticationType` 기준으로 필터링합니다. |
| 연결 가져오기 | `fusion_connections_get` | 읽기 | 단일 연결에 대한 세부 사항을 반환합니다. |
| 키 검색 | `fusion_keys_search` | 읽기 | 키를 나열합니다. `name`, `typeName`, `teamId` 기준으로 필터링합니다. |
| 키 가져오기 | `fusion_keys_get` | 읽기 | 단일 키에 대한 세부 정보를 반환합니다. |

프롬프트 예:

* _앞으로 30일 후에 만료되는 연결과 해당 연결을 사용하는 시나리오_

## 동료

이 문서의 모든 도구는 동일한 읽기/쓰기 설정 및 사용자의 권한에 따라 Coworker(독립 실행형 및 Fusion 오른쪽 레일)에서 모두 사용할 수 있습니다.

## 도구 업데이트 방법

Adobe이 새로운 버전의 Fusion MCP 서버를 출시하면 연결된 에이전트가 업데이트된 도구 세트를 자동으로 수거합니다. 다시 연결할 필요가 없습니다.
