# 저장소에서 파일 버전 기록 보기

저장소 개요는 [저장소 개요](/help/workfront-fusion/set-up-and-manage-workfront-fusion/use-workfront-storage/storage-overview.md)를 참조하십시오.

Adobe 스토리지의 파일에는 여러 버전이 있을 수 있습니다.

## 버전 내역 보기

1. Workfront Fusion의 왼쪽 탐색에서 **저장소**&#x200B;를 클릭합니다.
1. 버전을 보려는 파일이 포함된 저장소 및 폴더로 이동합니다.
1. 파일을 선택하고 작업 표시줄에서 **&quot;버전&quot;**&#x200B;을(를) 클릭합니다.
**버전 기록** 패널이 열립니다.
버전은 가장 최신 버전으로 나열되며, 각각 다음 내용이 표시됩니다.
   * 버전 번호
   * 일자
   * **다운로드** 단추

   현재(최신) 버전은 **&quot;현재&quot;** 배지로 레이블이 지정됩니다.

특정 버전을 다운로드하려면 [저장소에서 파일 다운로드] 문서에서 [특정 버전 다운로드](/help/workfront-fusion/set-up-and-manage-workfront-fusion/use-workfront-storage/download-files-from-storage.md#download-a-specific-version)를 참조하십시오.
