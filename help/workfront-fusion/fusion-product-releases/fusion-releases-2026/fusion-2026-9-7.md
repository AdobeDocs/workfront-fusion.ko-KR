# Workfront Fusion 릴리스 활동: 2026년 9월 7일 주

이 페이지에서는 2026년 9월 7일이 있는 주에 Adobe Workfront Fusion에서 향상된 기능을 모두 설명합니다.

최근 모든 변경 사항의 목록은 [Adobe Workfront Fusion 릴리스 활동](/help/workfront-fusion/fusion-product-releases/fusion-release-activity.md)을 참조하십시오.

Workfront Fusion의 최근 버그 수정 목록을 보려면 [Workfront 유지 관리 업데이트](https://experienceleague.adobe.com/ko/docs/workfront-known-issues/releases/current-updates) 페이지를 참조하고 Workfront Fusion 유지 관리 업데이트 레이블이 지정된 업데이트를 확인하십시오.

## 사용자 지정 웹 후크에 대한 새로운 인증 유형

이제 API 키 인증 및 HMAC 서명이라는 두 가지 새로운 방법을 사용하여 사용자 지정 웹 후크를 승인할 수 있습니다. 이제 API 키 인증이 새 웹후크에 대한 기본 인증 유형입니다. 이전 권한 부여 유형은 계속 사용할 수 있으며 권한 부여가 없는 경우 빈 값을 선택할 수 있습니다.

자세한 내용은 [웹후크](/help/workfront-fusion/references/apps-and-modules/universal-connectors/webhooks-updated.md)를 참조하십시오.

## 시나리오 설명의 새 AI로 설명 버튼

이제 시나리오 설정 패널의 설명 필드에서 AI로 설명 을 클릭하여 AI가 시나리오의 모듈 및 구성을 기반으로 시나리오에 대한 설명을 자동으로 생성하도록 할 수 있습니다.

자세한 내용은 [시나리오 설정 구성](/help/workfront-fusion/create-scenarios/config-scenarios-settings/configure-scenario-settings.md#description)을 참조하십시오.

## Fusion AEM MCP 커넥터

Adobe Experience Manager의 자체 MCP(Model Context Protocol) 서버에 일반 영어 프롬프트를 보내고, AI 모델이 이를 수행하는 데 필요한 Adobe Experience Manager 작업을 결정하도록 합니다. 이 새 전용 커넥터는 다음과 같은 단일 모듈인 사용자 프롬프트 처리 를 추가합니다.

* OAuth를 사용하여 Adobe Experience Manager에 연결합니다. 수동 자격 증명이 필요하지 않습니다.
* 지침을 해석하고 필요한 Adobe Experience Manager 작업(사이트, 에셋, 콘텐츠 조각, 폴더, 콘텐츠 저장소 및 콘텐츠 AI)을 호출하여 이를 수행합니다.
* AI가 수행할 수 있는 읽기 전용 및 쓰기/삭제 작업을 제한하여 무인 시나리오에서도 예기치 않은 파괴적인 작업을 수행할 수 없습니다.
* Adobe의 자체 AI 서비스를 기본적으로 사용하거나 원하는 경우 자체 OpenAI, Anthropic Claude 또는 Amazon Bedrock 키를 사용합니다.

자세한 내용은 [Adobe Experience Manager MCP 모듈](/help/workfront-fusion/references/apps-and-modules/adobe-connectors/aem-mcp-modules.md)을 참조하세요.

## Workfront Fusion 커넥터의 새 내보내기 시나리오 모듈

이제 Workfront Fusion 커넥터에는 시나리오 내보내기 모듈이 포함되어 있으므로 시나리오 내에서 직접 하나 이상의 시나리오에 대한 블루프린트를 내보낼 수 있습니다.

자세한 내용은 [Workfront Fusion 모듈](/help/workfront-fusion/references/apps-and-modules/adobe-connectors/workfront-fusion-modules.md)을 참조하십시오.
