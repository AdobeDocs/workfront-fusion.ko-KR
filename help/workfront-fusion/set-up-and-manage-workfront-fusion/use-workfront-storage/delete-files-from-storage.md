# 저장소에서 파일 삭제

저장소 개요는 [저장소 개요](/help/workfront-fusion/set-up-and-manage-workfront-fusion/use-workfront-storage/storage-overview.md)를 참조하십시오.

1. Workfront Fusion의 왼쪽 탐색에서 **저장소**&#x200B;를 클릭합니다.
1. 삭제할 파일이 포함된 저장소 및 폴더로 이동합니다.
1. 테이블에서 파일을 클릭하여 선택합니다.
1. 작업 표시줄에서 **&quot;삭제&quot;**&#x200B;을(를) 클릭합니다.
1. 파일을 삭제할지 확인합니다.


파일이 저장소 영역에서 제거됩니다.

>[!NOTE]
>
>파일만 삭제할 수 있습니다. 이 버전에서는 폴더 삭제가 지원되지 않습니다.
