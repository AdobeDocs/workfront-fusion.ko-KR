# Workfront Fusion 릴리스 활동: 2026년 10월 12일이 있는 주

이 페이지에서는 2026년 10월 12일이 있는 주에 Adobe Workfront Fusion에서 향상된 기능을 모두 설명합니다.

최근 모든 변경 사항의 목록은 [Adobe Workfront Fusion 릴리스 활동](/help/workfront-fusion/fusion-product-releases/fusion-release-activity.md)을 참조하십시오.

Workfront Fusion의 최근 버그 수정 목록을 보려면 [Workfront 유지 관리 업데이트](https://experienceleague.adobe.com/ko/docs/workfront-known-issues/releases/current-updates) 페이지를 참조하고 Workfront Fusion 유지 관리 업데이트 레이블이 지정된 업데이트를 확인하십시오.

## AWS S3, Azure DevOps 및 SharePoint에 대한 통합 연결

오래 지속되는 비밀을 저장하지 않고 더 쉽게 보안 연결을 만들 수 있도록 AWS S3, Azure DevOps 및 SharePoint 커넥터에 통합 연결 지원을 추가했습니다.

이렇게 하면 조직의 ID 공급자를 사용하여 클라이언트 암호 또는 기타 정적 자격 증명 대신 임시 자격 증명으로 Workfront Fusion을 인증할 수 있습니다. 이미 Azure AD/Microsoft Entra ID 또는 AWS IAM ID 공급자를 사용하는 커넥터 간에 설정 프로세스를 일관되게 유지하면서 보다 안전한 연결 옵션을 제공합니다.

자세한 내용은 다음 문서를 참조하십시오.

* [AWS S3 모듈](/help/workfront-fusion/references/apps-and-modules/third-party-connectors/aws-s3-modules.md)
* [Azure DevOps 모듈](/help/workfront-fusion/references/apps-and-modules/third-party-connectors/azure-dev-ops.md)
* [SharePoint 모듈](/help/workfront-fusion/references/apps-and-modules/third-party-connectors/sharepoint-modules.md)
