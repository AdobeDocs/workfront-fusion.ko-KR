# 저장소에 파일 업로드

저장소 영역을 사용하여 Workfront Fusion 내에서 Adobe 클라우드 저장소로 파일을 업로드할 수 있습니다.

업로드는 폴더 내부(최상위 폴더 목록이 아님)를 검색할 때 사용할 수 있습니다.

* 저장소 개요는 [저장소 개요](/help/workfront-fusion/set-up-and-manage-workfront-fusion/use-workfront-storage/storage-overview.md)를 참조하십시오.
* 업로드 시나리오를 만드는 방법에 대한 지침은 [저장소에서 시나리오 만들기](/help/workfront-fusion/set-up-and-manage-workfront-fusion/use-workfront-storage/create-scenarios-from-storage.md)를 참조하십시오.


## 파일 업로드

1. Workfront Fusion의 왼쪽 탐색에서 **저장소**&#x200B;를 클릭합니다.
1. 파일을 업로드할 저장소 및 폴더로 이동합니다.
1. **&quot;파일 업로드&quot;** 드롭다운 단추를 클릭합니다.
1. 직접 업로드하려면 **&quot;파일 업로드&quot;**&#x200B;를 선택하십시오.

   파일 선택기가 열립니다.
1. 업로드할 파일을 선택합니다.

   **진행률 배너**&#x200B;가 오른쪽 위에 표시됩니다.

   * 파일 이름
   * 업로드 진행률
   * 전송된 바이트
   * 업로드를 중지하는 **취소** 단추

업로드 후 파일이 폴더 목록에 나타납니다. Adobe 저장소가 백엔드에서 파일을 처리하는 동안 **Size** 열에 *&quot;처리 중...&quot;*&#x200B;이(가) 일시적으로 표시될 수 있습니다. 처리가 완료된 후 실제 파일 크기가 나타납니다. 페이지를 새로 고침하여 이를 확인할 수 있습니다.

## 업로드 제한

* 최대 파일 크기: **5GB**.
