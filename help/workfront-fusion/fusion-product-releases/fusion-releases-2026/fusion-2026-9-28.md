# Workfront Fusion 릴리스 활동: 2026년 9월 28일의 주

>[!IMPORTANT]
>
>2026년 10월 1일부터 Adobe Workfront Fusion은 Adobe 통합 경험으로의 마이그레이션을 완료했습니다.
>이제 모든 Fusion Webhook URL이 `adobe.com` 도메인에서 종료됩니다.

이 페이지에서는 2026년 9월 28일이 있는 주에 Adobe Workfront Fusion에서 향상된 기능을 모두 설명합니다.

최근 모든 변경 사항의 목록은 [Adobe Workfront Fusion 릴리스 활동](/help/workfront-fusion/fusion-product-releases/fusion-release-activity.md)을 참조하십시오.

Workfront Fusion의 최근 버그 수정 목록을 보려면 [Workfront 유지 관리 업데이트](https://experienceleague.adobe.com/ko/docs/workfront-known-issues/releases/current-updates) 페이지를 참조하고 Workfront Fusion 유지 관리 업데이트 레이블이 지정된 업데이트를 확인하십시오.

## Marketo 커넥터 업데이트

Marketo에서 벌크 추출과 상호 작용할 수 있도록 다음 세 가지 새로운 모듈을 추가했습니다.

* 대량 추출 작업 만들기
* 일괄 추출 작업 상태 가져오기
* 벌크 추출 파일 다운로드

또한 사용자 지정 API 호출 모듈에 원시 JSON 요청 본문을 추가하는 기능도 추가했습니다.

자세한 내용은 [Marketo 모듈](/help/workfront-fusion/references/apps-and-modules/adobe-connectors/adobe-marketo-modules.md)을 참조하세요.

## Fusion MCP 커넥터를 사용하여 Fusion을 AI 에이전트에 연결

Adobe Workfront Fusion을 AI 에이전트와 함께 사용할 수 있도록 Workfront Fusion MCP 서버를 만들었습니다. 이제 이 서버를 사용하여 시나리오를 검사하고, 실행을 검토하고, 연결을 관리하고, 기존 Fusion 권한을 사용하여 승인된 작업을 수행할 수 있습니다. 이렇게 하면 에이전트 환경을 종료하지 않고도 자연어로 된 Fusion을 사용하여 보다 쉽게 작업할 수 있습니다.

자세한 내용은 [Adobe Workfront Fusion MCP 서버 구성](/help/workfront-fusion/set-up-and-manage-workfront-fusion/use-fusion-mcp-server/configure-fusion-mcp-server.md)을 참조하십시오.

## 새로운 Adobe Marketo Engage MCP 커넥터

이제 새로운 Adobe Marketo Engage MCP 커넥터를 사용하여 Workfront Fusion을 Adobe Marketo EngageMCP 서버에 직접 연결할 수 있습니다.

이제 개방형 일반 영어 지침을 입력할 수 있으며, 이를 수행하기 위해 필요한 Marketo 작업을 AI 모델이 결정합니다.AI가 수행할 수 있는 읽기 전용 및 쓰기/삭제 작업을 제한할 수 있으므로 무인 시나리오도 승인하는 작업으로 제한할 수 있습니다.

모듈은 기본적으로 Adobe의 자체 관리 AI 서비스를 사용하거나 원하는 경우 자체 OpenAI, Anthropic Claude 또는 Amazon Bedrock 키를 사용할 수 있습니다.

자세한 내용은 [Adobe Marketo Engage MCP 모듈](/help/workfront-fusion/references/apps-and-modules/adobe-connectors/adobe-marketo-engage-mcp-module.md)을 참조하세요.
