# 저장소에서 파일 다운로드

Fusion 저장소 영역을 사용하면 Adobe 저장소에서 파일을 다운로드할 수 있습니다.

저장소 개요는 [저장소 개요](/help/workfront-fusion/set-up-and-manage-workfront-fusion/use-workfront-storage/storage-overview.md)를 참조하십시오.

## 파일 다운로드

1. Workfront Fusion의 왼쪽 탐색에서 **저장소**&#x200B;를 클릭합니다.
1. 다운로드할 파일이 포함된 저장소 및 폴더로 이동합니다.
1. 테이블에서 파일을 클릭하여 선택합니다.
1. 표시되는 작업 표시줄에서 **다운로드**&#x200B;를 클릭합니다.

**진행률 배너**&#x200B;가 오른쪽 위에 표시됩니다.

* 파일 이름
* 다운로드 진행률
* 전송된 바이트
* 다운로드를 중단하는 **취소** 단추

파일은 브라우저의 기본 다운로드 위치에 저장됩니다.

## 특정 버전의 파일 다운로드

1. Workfront Fusion의 왼쪽 탐색에서 **저장소**&#x200B;를 클릭합니다.
1. 다운로드할 파일이 포함된 저장소 및 폴더로 이동합니다.
1. 파일을 선택하고 작업 표시줄에서 **&quot;버전&quot;**&#x200B;을(를) 클릭합니다.
1. **버전 기록** 패널에서 다운로드할 버전 옆의 **다운로드**&#x200B;를 클릭합니다.

다운로드가 실패하면 알림 메시지가 나타납니다. *&quot;다운로드 실패 — 파일을 다운로드할 수 없습니다. 다시 시도하십시오.&quot;*

파일 버전에 대한 자세한 내용은 [저장소에서 파일 버전 기록 보기](/help/workfront-fusion/set-up-and-manage-workfront-fusion/use-workfront-storage/view-storage-file-version-history.md)를 참조하십시오.
